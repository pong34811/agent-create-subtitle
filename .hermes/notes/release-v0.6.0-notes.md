## 🚀 Release v0.6.0 — ปรับขั้นตอนถอดเสียงไทยและตรวจข้อความ 963 cue

รอบนี้ตรวจซับทุก cue ด้วยกฎ (อ่านเองบางส่วน) แล้วแก้เฉพาะสิ่งที่พิสูจน์ได้ด้วยตัวเลข ส่วนที่ทดลองแล้วไม่ดีขึ้นจะ **ไม่ใส่** และบันทึกไว้ให้ไม่ต้องลองซ้ำ

---

### 🔎 ข้อผิดพลาดที่พบในซับ และแก้แล้ว

1. **`[ฟังไม่ชัด]` หลุดเป็นข้อความบนจอ 15 จุด** — ตัวแทนที่ไม่ควรให้คนดูเห็น → ตัดทิ้ง ไม่สร้าง cue ที่เหลือแต่ตัวแทน
2. **สระอำแบบแยกชิ้น** `ทํา น้ํา ถ้ํา คํา` แทน `ทำ` — หน้าตาเหมือนกันแต่ค้นหาและตรวจสะกดไม่ได้ → แปลงให้ถูก
3. **cue เป็นกำแพงข้อความ** สูงสุด 290 ตัวอักษร (ไทม์ไลน์ 26) จากการรวม segment ที่เวลาซ้อนกัน → แยกเป็น cue ของตัวเอง
4. เสียงลากซ้ำ `อื้ออื้ออื้อ…` 20+ ครั้ง → ย่อเหลือ 2 ครั้ง
5. ชื่อเกมผิดในพรอมต์เดิม: "Heavy Rain Shooter" (ไทม์ไลน์ 9), "Vengeance" (ไทม์ไลน์ 1)

ผลหลังแก้: **963 → 957 cue, ซ้อนกัน 0, ยาวเกิน 0, ตัวแทน `[ฟังไม่ชัด]` 0**

### 🛠️ การปรับขั้นตอนถอดเสียง

- **`vocab/games.json`** — ใส่ชื่อเกมและคำสะกดที่ต้องการในพรอมต์ตามชื่อไทม์ไลน์ แก้ชื่อเกมได้ 2/2 ไฟล์ที่ทดสอบ
- **พรอมต์บังคับ segment ≤ 4 วินาที** — segment ยาวสุดจาก 44 s เหลือ 4 s (ไทม์ไลน์ 16) ทำให้เวลาของ cue เดาน้อยลง
- **`scripts/thai_text.py`** — ทำความสะอาดข้อความแบบกำหนดผลได้ ใช้ในตัวสร้าง cue
- **`scripts/check_thai_text.py`** (`run_pipeline.py check`) — กฎตรวจภาษาไทย: อักขระต่างชาติ, วรรณยุกต์ซ้อน, สระลอย, ตัวอักษรลากยาว, cue ยาวเกิน, ความเร็วอ่าน, คำนอกพจนานุกรม, วงเล็บบันทึกเสียง
